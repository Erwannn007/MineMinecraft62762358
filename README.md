# MineMinecraft

Jeu perso : monde ouvert infini façon Minecraft, en pixel art isométrique (vue 3/4 du dessus).
Fonctionne dans le navigateur (GitHub Pages), s'installe comme une app sur iPhone (Partager → Sur l'écran d'accueil)
et marche hors ligne.

## Contrôles

| Action | PC | Tactile | Manette (Ayn Thor, Xbox…) |
|---|---|---|---|
| Se déplacer | ZQSD / WASD / flèches | Joystick (moitié gauche) | Stick gauche |
| Sauter / nager | Espace | Bouton ↑ | A |
| Descendre / s'accroupir | Maj | Bouton ↓ | B |
| Viser | Souris | Doigt | Stick droit (sinon visée auto devant) |
| Casser / attaquer | Clic gauche (maintenu) | Appui long | RT |
| Poser / utiliser / manger | Clic droit | Toucher | LT |
| Barre rapide | 1-9, molette | Toucher la case | LB / RB, croix ←/→ |
| Inventaire / artisanat | E | Bouton ••• | Y |
| Jeter l'objet | Q | Bouton ⤓ | X / croix ↓ |
| Voler (créatif) | F | Bouton ailes | Croix ↑ |
| Sprint | Ctrl | Joystick à fond | L3 |
| Pause | Échap | Bouton ‖ | Start |
| Zoom | Ctrl + molette | Options | Options |

## Lancer en local

```
python3 -m http.server 8000
```
puis ouvrir http://localhost:8000
